# Утя Дома — сайт

Прототип обновлённого сайта [утядома.рф](https://утядома.рф): статичный HTML/CSS/JS, без сборки.

## Запуск
Открыть `index.html` в браузере или поднять любой статический сервер:

```bash
python -m http.server 5173
```

## Структура
- `index.html` — вся страница и стили
- `advantages.js`, `process.js`, `it.js`, `rest.js` — анимации и логика блоков
- `frames/` — кадры скролл-анимаций (кресло с Утей, ноутбук)
- `assets/` — картинки, иконки, логотипы технологий
- `tools/` — Python-скрипты: нарезка видео в кадры, чистка фона, подготовка картинок

Библиотеки подключаются с CDN: GSAP + ScrollTrigger, Lenis.
